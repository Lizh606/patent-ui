# Spacing Scale (4px Grid)

Our spacing system relies on an exact, mathematically clean 4px baseline grid. Values are mapped directly through `--pef-space-*` tokens:

*   `--pef-space-0`: `0px`
*   `--pef-space-1`: `4px` — Micro padding between inline badges and texts
*   `--pef-space-2`: `8px` — Margin between related inputs, sub-heading layouts
*   `--pef-space-3`: `12px` — Inset padding for dense tables, small panels
*   `--pef-space-4`: `16px` — Default padding for containers and stats cards
*   `--pef-space-5`: `20px` — Section grid gap boundaries
*   `--pef-space-6`: `24px` — Standard page margin padding (`--pef-content-padding`)
*   `--pef-space-8`: `32px` — Spacious department-level partition gaps
*   `--pef-space-10`: `40px` — Workspace title-bar spacings
*   `--pef-space-12`: `48px` — Empty state canvas clearances
