# Typography Scale (T1 - T7)

Typography in Patent EvidenceFlow is mapped to the semantic scale `text-t1` through `text-t7`. It does not scale dynamically with viewport layout ranges, preventing clipping, and ensures readable data density across enterprise screens.

| Scale Token | Font Size | Line Height | Font Weight | Primary Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `text-t1` | `28px` | `36px` | `semibold` (600) | Rare large splash metrics, main workspace indices |
| `text-t2` | `24px` | `32px` | `semibold` (600) | Root page layout headings (e.g. Export Packages) |
| `text-t3` | `20px` | `28px` | `semibold` (600) | Card headers, main layout division sections |
| `text-t4` | `16px` | `24px` | `semibold` (600) | Form headers, table group section titles |
| `text-t5` | `14px` | `22px` | `regular` (400) | Primary table density body lines, descriptions, input texts |
| `text-t6` | `12px` | `18px` | `regular` (400) | Helper instructions, captions, form annotations |
| `text-t7` | `13px` | `20px` | `regular` (400) | JetBrains Mono high-density patent numbers, ID strings |
